# Java-BootCamp: Ultimate Java Mastery Series ☕

A comprehensive wrap-up and code repository for the **Master Java Bundle** (Ultimate Java Mastery Series) by [Code With Mosh](https://codewithmosh.com/). This repository serves as my personal workspace for practical implementations, exercises, and summary notes covering everything from Java fundamentals to advanced backend concepts.

## 📚 Course Outline & Topics Covered

### Part 1: Java Fundamentals
This section covers the core syntax and foundations of Java programming, clean coding, and debugging.
* **Basics & Variables:** Primitive vs. Reference types, Strings, Arrays, Multi-dimensional Arrays, Constants, and Arithmetic Expressions.
* **Control Flow:** If statements, Ternary operators, Switch statements, For loops, While/Do-While loops, and For-Each loops.
* **Clean Coding:** Creating/Extracting methods, refactoring repetitive patterns, and writing maintainable code.
* **Debugging:** Identifying syntax/runtime errors, using debugging tools, and packaging Java applications.
* **Projects/Exercises:** FizzBuzz, Mortgage Calculator, and Payment Schedule.

### Part 2: Object-Oriented Programming (OOP)
This section dives into software design principles, building robust classes, and architectural best practices.
* **Classes & Objects:** Memory allocation, Encapsulation, Getters/Setters, Abstraction, Constructors (and Overloading), and Static Members.
* **Coupling & Dependency:** Understanding coupling, reducing dependencies, and implementing Dependency Injection.
* **Inheritance & Polymorphism:** The Object class, Access Modifiers, Overriding methods, Upcasting/Downcasting, Comparing objects, Abstract classes, and Final classes.
* **Interfaces:** Interface Segregation Principle, Fields and Static/Private methods in interfaces, and choosing between Interfaces vs. Abstract Classes.
* **Projects/Exercises:** Refactoring procedural code (Mortgage Calculator) to OOP, MyTube Video Platform project.

### Part 3: Advanced Topics
This section explores complex Java features essential for high-performance and scalable applications.
* **Exceptions:** Handling errors, throwing exceptions, and creating custom exceptions.
* **Generics:** Creating type-safe, reusable classes and methods.
* **Collections Framework:** Deep dive into data structures like Lists, Sets, Maps, and Queues.
* **Functional Programming:** Lambda expressions, Functional Interfaces, and the `java.util.function` package.
* **Streams API:** Efficiently processing, filtering, and mapping collections of data.
* **Concurrency & Multi-threading:** Thread lifecycles, synchronization, concurrent collections, and multithreaded programming.
* **Asynchronous Programming:** Working with Callables, Futures, and the CompletableFuture API.
